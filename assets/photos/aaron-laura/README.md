# Aaron and Laura

사진을 클릭하면 해당 이미지 파일을 열어 볼 수 있습니다. 원본 파일 이름을 유지하고 웹용 확장자만 `.webp`로 바꿨습니다. `-thumb`는 작은 미리보기 파일입니다.
